# מתכנן טיולים

דף אחד (GitHub Pages) לתכנון טיול לפי ימים: מפה (Google Maps), עצירות עם זמני שהייה ואופן הגעה לכל קטע, לוח זמנים ליום, מזג אוויר, סיכום עם תובנות, רשימת ציוד משותפת, וסנכרון בזמן אמת בין המשתתפים (Firestore).

## למסור למישהו טיול משלו

לא צריך שום הקמה. בדף:

1. `טיולים ▾` ← `＋ טיול חדש` ← שם הטיול. אפשר להתחיל מרשימת ציוד בסיסית.
2. הדפדפן עובר לכתובת של הטיול החדש, למשל `https://thedimag.github.io/gdansk-trip-map/?trip=rome-ab12cd`.
3. `טיולים ▾` ← `🔗 העתק קישור לטיול` ושולחים. כל מי שיש לו את הקישור רואה ועורך את אותו תכנון, מכל מכשיר.

כל טיול הוא מסמך נפרד ב-Firestore (`trips/<id>`), ולכן טיול חדש לא נוגע בטיולים אחרים. הטיול בלי `?trip=` בכתובת הוא טיול ברירת המחדל (גדנסק).

## למפתח: להריץ עותק משלך

1. ליצור ריפו ציבורי ולהפעיל GitHub Pages (Settings → Pages → Deploy from a branch → main / root).
2. Google Cloud: מפתח API עם הגבלה לדומיין של האתר ולשירותים Maps JavaScript API, Routes API, Places API (New).
3. Firebase: פרויקט עם Firestore. כללים (קובץ `firestore.rules`): קריאה וכתיבה לאוסף `trips` בלבד.
4. הדף נבנה מתבנית: הנתונים, הגדרות Firebase ומפתח המפות מוזרקים בזמן הבנייה (ראו `build_planner.py` בתיקיית הבנייה). לטיול חדש אין צורך בנתוני מקומות מראש, הכול נוסף דרך החיפוש בדף.

## גיבוי

`backup_to_drive.py` שומר כל שעה (launchd) עותק של התכנון לתיקיית Google Drive מסונכרנת, כולל גרסה קריאה (`מסלול.md`). `restore_from_drive.py <קובץ>` משחזר עם אישור.
